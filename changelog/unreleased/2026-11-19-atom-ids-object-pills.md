- **Text that takes an atom's place is a new paragraph with a new id.** Typing or pasting over a selected atom, over a run of atoms, over atoms up to the start of the next, or from inside a label used to leave the atom's `ParagraphAttrs::id` on the text. An app that keys an atom's content by id then took the text for the atom. The id now comes from the counter of `set_paragraph_ids`, and an id that named an atom never names text.
- **A rich paste over selected atoms keeps their line**, as typed text and a plain paste do. `paste_html` used to remove the atoms with their line break, so the pasted text joined the paragraph beside them.
- **A pill whose label is the object character (U+FFFC) alone and that has an icon draws the icon only.** The font's glyph for the character ("OBJ" in a box) is not drawn and takes no room, so the chip is the icon and its padding. A pill without an icon draws as before.
