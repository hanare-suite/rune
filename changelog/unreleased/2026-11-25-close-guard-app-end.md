- Window close: when the last main window's close would end the app, a window that holds back its close (`App::on_close_guard`) asks first and the app stays, and a cancelled question drops that end (the app ends when its last window closes, asking again if it is guarded); a hidden `keep_running` window with its guard up counts for a macOS Quit and the app's end; a guard whose `ask` asks to close the window while it still holds no longer recurses; a macOS Quit meets a guard raised earlier in the same pass; a closed headless window stays closed until `{"reopen": true}`, and a re-entrant `ask` asks once in headless and `--desktop` runs too; on Windows a held app end no longer destroys the main window first.
- Window close: a `keep_running` window that closed (hid) after an app-end question with its guard down no longer holds the app open forever, and a window that answers the app-end question by closing itself ends the app in that turn.
