- Window close: when the close of the last main window would end the app and another open window, or a hidden `keep_running` one, holds back its close (`App::on_close_guard`), that close is held too: the main window stays, the guarded windows ask once as for a held macOS Quit, and closing the main window again after the answer ends the app (or asks again if a guard still holds); a hidden `keep_running` window with its guard up counts for a macOS Quit; a guard whose `ask` asks to close the window while it still holds no longer recurses, in native, headless and `--desktop` runs; a macOS Quit meets a guard raised earlier in the same pass; on Windows a held main window is no longer destroyed by the fast exit.
