- Window close: added `App::on_close_guard(guarded, ask)`, which holds back the close button, `⌘W`, `Tx::close_window`, `AppHandle::close` and a macOS Quit (`⌘Q`, the menu, the Dock, logout) while `guarded(&state)` says true and runs `ask` instead, for unsaved changes; `Tx::quit`, `AppHandle::quit` and the end of a Windows session are not held, and on a user's close request `App::on_close_request` runs first (a `Defer` stands) before the guard and `App::on_close`, natively and headless. Headless scripts gained `{"close": true}` for the close button, and `--tree` carries `"closed": true` once the window closed (`Tx::close_window` runs the guard, then `on_close`, in a headless run too).
