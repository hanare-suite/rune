- **The fork's close guard, document marks and paragraph types follow upstream's.** `App::on_close_request(guarded, ask)` is now `App::on_close_guard(guarded, ask)`, since `App::on_close_request` is upstream's hook that answers a user's close request with a `CloseResponse`; the guard still also holds `Tx::close_window`, `AppHandle::close` and a macOS Quit, and a user's close request asks upstream's hook first. `Mark::Color` is upstream's `#rrggbb` string (`Mark::Color("#d93025".into())`), and `MarkColor` stays for `Mark::Highlight`. A field keeps `Color`, `Size`, `Family`, `Highlight` and `Baseline` as upstream keeps `Color`, once it is a document field: the paragraph-attribute methods (`set_paragraph_attrs`, `set_paragraph`, `format_paragraphs`, `set_paragraph_ids`, `insert_atom`) and `TextEdit::from_parts` with such a mark make it one, and `allow_marks` names the kinds itself. `Block`, `ParagraphStyle`, `PageFlow`, `ParagraphAttrs`, `ParagraphAlign` and `Baseline` are `rune-text` types that `rune` and `rune-edit` re-export; `PillChip` and `Span` gain public fields.
